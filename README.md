# 注音打擊王 ⚾

給小小棒球迷的注音鍵盤練習遊戲。使用 HTML、CSS、JavaScript，無需安裝套件，也不需要帳號或網路。

## 開始玩

1. 用 Chrome、Edge 或 Safari 開啟這個資料夾裡的 `index.html`（直接雙擊即可）。
2. 將電腦切換成**英文輸入法**。
3. 選擇練習範圍，按「開始打擊」。
4. 看見注音後，按實體鍵盤對應的按鍵。例如「ㄅ」按 `1`，「ㄆ」按 `Q`。

也可以在這個資料夾執行 `python3 -m http.server 8000`，再開啟 http://localhost:8000。

## 遊戲規則

- 每位打者答錯 1 次記 1 個好球，累積 3 個好球三振出局，換下一位打者；答對擊出安打後也會換打者、好球數歸零。
- 累積 **3 人出局就結束這一關**，不限安打次數；超過十位打者會自動補充題目。
- **每次答題有 5 秒**，畫面顯示倒數條，最後 1.5 秒變成橘色提醒。5 秒到仍未答對時，投手投出一球、打者未揮棒，記一次超時和一個好球；投球演出期間不接受作答、不重複計錯。剛好到第 5 秒才按對也算超時。
- 前兩次答錯保留同一注音，**沿用原本五秒倒數，不重設時間**；只有超時投球後尚未三振，才開始新的五秒倒數。第三次答錯或超時三振，換下一位打者。切到其他分頁時暫停答題計時，回來接著倒數。
- 比分板顯示黃色好球燈、紅色出局燈，以及最近十位打者的安打（H）、全壘打（HR）和三振（K）紀錄。
- 一般答對擊出一支安打，打者上一壘，所有跑者前進一壘；回到本壘得 1 分。
- **題目首次出現後 1 秒內（含 1 秒）直接答對，擊出全壘打**，帶回打者和所有壘上跑者；滿壘可拿 4 分，得分後壘包清空。已答錯或超時後的快速重試不會觸發全壘打。
- 擊球後隨機出現滾地安打或高飛安打：可以看到投球、揮棒、擊球火花、球的尾跡和影子，以及金色球衣跑者沿壘線衝刺。兩種球都依一壘安打規則推進。
- 跑者抵達壘包後才更新壘包圖和得分；一般安打演出約 3 秒，全壘打約 4.3 秒，可以看到跑者繞壘回家及得分提示。演出不消耗下一題的答題時間。
- 前兩次答錯會提示正確按鍵，保留同一題；第三次答錯顯示「三振出局」，換一道題。三振不會推進壘上跑者。
- 每關壘包、得分、好球與出局數重新計算；10 支一壘安打會得到 7 分，仍可繼續比賽直到三出局。
- 連續答對紀錄在按錯時歸零；正確率是「正確按鍵次數 ÷ 全部作答次數」。
- **熟練度 0–100 分**：首次 0.5 秒內答對拿 100 分，速度越慢分數越低；接近 5 秒為 20 分。答錯或超時拿 0 分。本關熟練度是所有作答分數的平均，因此準確度也會影響結果。
- 同一打者重試時，熟練度使用累積的實際答題時間，排除動畫和分頁暫停；不會因倒數重設而把慢速重試當成快速答對。結算的平均與最快答對時間也使用這個累積時間。
- 熟練度稱號：0–39 分「新秀打者」、40–69 分「穩定打者」、70–89 分「快手強打」、90–100 分「注音打擊王」。每關重新計算，結束顯示熟練度、稱號、平均與最快答題時間、全壘打及超時次數。
- 結算顯示需要再練的注音；若全部答對，顯示本輪練過的符號。
- 可關閉「顯示按鍵提示」練習記憶；按錯或點「給我提示」仍能看到答案。
- 聲音預設開啟，按「開始打擊」後啟用。包含循環球場配樂、中文加油語音與拍手，以及投球、擊球、跑步、觀眾歡呼、三振和得分音效。
- 右上角「配樂」和「加油」可以分別開關；「聲音」是總開關，關閉會立即停止所有聲音，重新開啟後會恢復比賽中的配樂。
- 背景旋律已加強，擊球及加油聲調整為較平衡的音量。點「音量」可以分別調整背景音樂和音效與加油（預設均為 75%，已依音源強弱混音）；調整會即時生效，滑桿設為零可單獨靜音。
- 本關結束時停止背景音樂與加油語音，再播放結算旋律；切換到其他分頁時暫停聲音，回到遊戲恢復配樂。重新挑戰不會疊加多條音樂。
- 配樂和音效由瀏覽器合成；加油語音是隨專案附上的本機 `assets/cheer.wav`（由系統 Meijia 語音產生），不依賴線上語音服務。開啟系統的「減少動態效果」時，使用短暫靜態提示。
- 螢幕鍵盤也可以點選。目前練習的是注音鍵位，不含中文組字與選字。

## 練習範圍

- **新秀練習**：ㄅ、ㄆ、ㄇ、ㄈ、ㄉ、ㄊ、ㄋ、ㄌ。先練完一組再重複，前八位打者各練一個符號。
- **完整練習**：37 個注音符號。
- **進階練習**：37 個注音符號及 4 個聲調按鍵（ˊ、ˇ、ˋ、˙）。一聲沒有獨立按鍵。

使用臺灣標準（大千式）注音配置。配置參考：[Microsoft 繁體中文輸入法](https://support.microsoft.com/zh-tw/windows/hardware/input-devices/microsoft-traditional-chinese-ime)。

## 和孩子一起改程式

可以先從一個小改變開始，存檔後重新整理瀏覽器就看得到結果：

- 在 `index.html` 搜尋「小小強打隊」，換成自己的球隊名稱。
- 在 `style.css` 的 `:root` 修改 `--gold`，換掉球隊的重點色。
- 在 `game-core.js` 修改 `ROOKIE`，決定新秀模式要練哪幾個注音。

電腦版使用左側「球場＋同寬鍵盤」、右側題目面板的版型，依視窗可用高度縮放球場，讓球場、題目和鍵盤同時呈現。手機版維持直向排列。

檔案分工：`index.html` 是畫面內容；`style.css` 是基本外觀；`ballpark.css` 是擊球演出的外觀；`challenge.css` 是倒數、熟練度與音量控制外觀；`layout.css` 是同視窗球場與鍵盤版型；`game-core.js` 是題目、計分、熟練度和跑壘規則；`app.js` 是操作流程與倒數計時；`effects.js` 是球路、跑者動畫及音效；`assets/` 裡是本機球場插圖與加油語音。

## 驗證遊戲規則

已安裝 Node.js 時，執行 `node --test tests/*.test.cjs`。測試涵蓋注音對應、補題、跑壘、三振及三出局、五秒截止、1 秒全壘打邊界、滿貫得分、答錯倒數與熟練度、結算及重新挑戰。
